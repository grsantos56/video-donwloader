# Social Media Video Downloader MVP

A modern, clean, and lightweight Single Page Application (SPA) designed to download videos and audio from various social media networks.

## Features
- Paste links from YouTube, TikTok, Instagram, Twitter/X, Facebook, and more.
- Select format: Video (with audio) or Audio only.
- Select from available qualities.
- Modern interface built with Tailwind CSS and Lucide Icons.
- Lightweight Flask backend powered by `yt-dlp`.

## Tech Stack
- **Backend:** Python + Flask + yt-dlp
- **Frontend:** HTML5 + Tailwind CSS + Vanilla JS + Lucide Icons
